# Etjah systeme

A simple admin dashboard built with Next.js and React

[Source](https://github.com/Up-to-code/etjah_systeme) · [Issues](https://github.com/Up-to-code/etjah_systeme/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/etjah_systeme.git
cd etjah_systeme
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

First, run the development server:

